# Teacher-Performance-Prediction
Developed a Machine Learning-based Teaching Assistant Evaluation system using Python. Performed data cleaning, EDA, and visualization, and implemented Logistic Regression, Decision Tree, Random Forest, and KNN to classify teaching performance into Low, Medium, and High categories.

## Project Overview
This project focuses on analysing teaching assistant evaluation data and predicting teaching performance using Machine Learning. The model classifies teaching performance into three categories: Low, Medium, and High.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Understand patterns in teaching evaluation data.
- Build Machine Learning classification models.
- Compare model performance and identify the best model.

## Dataset
The dataset contains 151 records collected from the Statistics Department of the University of Wisconsin-Madison.

**Features:**
- Native Teacher
- Instructor
- Course
- Semester
- Class Size

**Target Variable:**
- Performance (Low, Medium, High)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)

## Results
The trained classification models are compared using accuracy and classification reports to identify the best-performing model.

**Best Model:** Random Forest

**Accuracy:** 64.74%

## Conclusion
This project demonstrates how Machine Learning can be used to analyse teaching evaluation data and classify teaching performance into different categories.
